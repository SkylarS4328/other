### Paragraphs and Headings
For paragraphs you use the tag `<p>` which is the opening tag and `</p>` as the closing tag and place the text you want inside of the opening and closing tags. for example if you wanted to write "this is a paragraph" in a paragraph you would write:
```
<p>this is a paragraph</p>
```
for headings the concept is the same, except the tag has numbers indicating the size of the heading you want. there are up to 6 different sized headings with 1 being the largest and 6 being the smallest. if you wanted to write a heading using the biggest size the tag would be `<h1>` with the text inside the opening and closing tags. so for example if you wanted to write "this is a heading" using h1 you would write:
```
<h1>this is a heading</h1>
```
### Links 
for links, you use the tags `a` and `href`. `a` is what makes the link have the desired text you want to be highlighted as the link, and `href` is how the link is referenced. so if you wanted to link the website cutecat.com with the highlighted text "look at these cats" you would write:
```
<a href="https://www.cutecat.com">look at these cats</a>
```
